01 / THE QUESTION

Can an AI system do more than process information?

Can it build an internal model of a changing world?
Can it detect when reality violates its expectations?
Can it generate hypotheses?
Can it test them through action?
Can it retain what it learns without treating memory as a fixed context window?

HEXIM explores these questions as an architectural problem.

    FULL ARCHITECTURE

    Ten layers. Each solves a different problem.

    LAYER 10WORLD / ENVIRONMENT

    Physical • Digital • Simulated. The changing world that generates experience.

    LAYER 9EXPERIENCE INTERFACE

    Sensors • Camera • Audio • Web • Human • Tools. Machine-readable interaction with the world.

    LAYER 8ECA — EXPERIENCE-CENTRIC ARCHITECTURE

    World Model • Prediction • Surprise • HEXIM-J • Hypothesis • Experiment • Action. The outer cognitive loop.

    LAYER 7MEMORY & LEARNING

    Memory OS • Consolidation • Skill Evolution. Retention across multiple timescales.

    LAYER 6SELF-DIRECTED SYSTEMS

    Initiative • Dream • Taste • Self-Model. What the system does when nobody asks.

    LAYER 5REASONING

    Planning • Verification • Decision. Deliberation before action.

    LAYER 4MEMORY INFRASTRUCTURE

    SMDRL • Seeds • Delta • Regeneration • Versioning • Migration • Verification. Deterministic memory infrastructure.

    LAYER 3REPRESENTATION

    VQ • Latent Structures • Knowledge Graphs. Compact, structured representation.

    LAYER 2COMPUTE

    MoE • GQA • Sparse Activation. Large capacity, small active compute.

    LAYER 1EFFICIENT RUNTIME

    Ternary • Scheduling • Cache • Device Adaptation. Practical intelligence on constrained devices.
